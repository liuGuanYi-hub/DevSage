# DevMind：程序员个人知识库 Agent 项目规划

## 项目定位

**DevMind / CodeVault Agent / Programmer Knowledge OS**

一句话介绍：

> 一个能够读取 Obsidian 笔记、项目代码和开发文档，通过 Agentic RAG
> 回答问题，并自动整理项目知识、生成学习总结和更新笔记的 AI 助手。

这个项目不是为了简历硬凑的 Demo，而是结合真实使用场景：

-   Obsidian 个人知识库
-   Codex / Vibe Coding 工作流
-   Markdown 学习笔记
-   软件项目代码
-   日常开发问题记录

目标：

> 打造属于程序员自己的 AI 第二大脑。

------------------------------------------------------------------------

# 为什么适合做这个项目

当前学习过程：

    学习资料
        ↓
    Markdown笔记
        ↓
    Obsidian
        ↓
    项目代码
        ↓
    AI辅助开发记录

存在的问题：

-   半年前解决的问题找不到
-   项目使用过的技术容易遗忘
-   知识分散在代码、博客、笔记中
-   AI生成内容无法沉淀

DevMind 解决：

让 AI 理解：

-   我学过什么
-   我写过什么项目
-   我遇到过什么问题
-   我的知识体系如何发展

"能回答"。

需要证明：

"回答质量"。

``` json
{
 "question":"Spring Boot端口占用如何解决",
 "expected_sources":[
   "Notes/Java/SpringBoot.md"
 ]
}
```

指标：

-   Recall@K
-   MRR
-   回答忠实度
-   回答相关性
-   工具调用准确率
