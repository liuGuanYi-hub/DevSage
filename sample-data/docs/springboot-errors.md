# Spring Boot 常见启动问题

## 8080 端口被占用

Spring Boot 默认可能使用 8080 端口。如果启动时出现端口绑定失败，可以先查询占用端口的进程：

```powershell
netstat -ano | findstr :8080
tasklist | findstr <PID>
```

确认进程用途后，可以结束占用进程，或者在 `application.yml` 中修改服务端口。修改端口前需要确认客户端、反向代理和部署配置是否仍然指向旧端口。

## 示例配置

示例项目当前将服务端口配置为 8081：

```yaml
server:
  port: 8081
```

## 判断原则

不要仅凭错误文本猜测原因。回答时应同时检查启动日志、端口配置文件和占用端口的操作系统进程，并在证据不足时明确说明还需要哪些信息。
